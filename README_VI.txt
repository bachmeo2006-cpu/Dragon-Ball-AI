DRAGONBOY AI - ANDROID STARTER PROJECT (v0.1)

Đây là MÃ NGUỒN Android Studio, chưa phải APK đã biên dịch và chưa phải bot tự farm hoàn chỉnh.

Đã có:
- Màn hình hướng dẫn cấp quyền overlay và Trợ năng.
- Nút nổi kéo thả.
- Bảng điều khiển demo Bắt đầu/Tạm dừng.

Chưa có:
- Chụp/đọc màn hình game bằng MediaProjection.
- Nhận diện quái, dấu X, vật phẩm vàng.
- Logic tự chọn mục tiêu, đánh, nhặt.
- Chạy nền 24/24.

Cách mở:
1. Cài Android Studio trên máy tính.
2. Chọn Open và mở thư mục DragonBoyAI.
3. Đồng bộ Gradle, build APK.
4. Cài APK lên Android.
5. Mở ứng dụng, cấp quyền hiển thị nổi và bật Trợ năng trong Cài đặt.

Lưu ý:
- Bạn hiện chỉ có điện thoại; để tự build APK cần máy tính có Android Studio hoặc một dịch vụ build Android.
- Chỉ bật Trợ năng cho ứng dụng bạn tin tưởng. Không nhập/gửi mật khẩu game.
- Bản demo chưa thực hiện thao tác tự động trong DragonBoy.
